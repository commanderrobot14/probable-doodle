## Introduction

This repository is your laboratory for learning GitHub. Think of it as a safe place to practice creating branches, making commits, and opening pull requests. Every change you make is progress: try something new, review the results, and iterate. If you ever get stuck, reach out, read the docs, or open an issue — the community is here to help.

Start small: click the exercise link below, create a branch, and make a tiny improvement. When you open a pull request, describe what you changed and why. Merging your first PR is a milestone — enjoy it! 🚀
